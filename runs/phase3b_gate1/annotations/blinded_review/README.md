# Rank-free Gate 1 relevance review

Pages are randomly ordered by a fixed seed and hide proposal arm, proposal prompt, candidate type, score, and rank. Each card shows the source frame with the proposal box and an enlarged source-resolution crop with a translucent mask overlay. The CSV is an annotation template; labels are evaluation-only. The key linking blind IDs to candidate IDs is kept separate from the pages.

The prior audit exposed some top-ranked examples, so full blinding is impossible. Do not infer or enter labels from rank. Candidate IDs were assigned after shuffling and are not rank-derived.
